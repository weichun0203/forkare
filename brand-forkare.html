前往下載（GitHub）
下載與安裝步驟
  1. 打開上面的連結，找到字體檔下載處。可看頁面右側的 Releases，或按綠色 Code → Download ZIP。
  2. 把下載的 ZIP 解壓縮，找到副檔名 .ttf 或 .otf 的字體檔。
  3. 只裝需要的三個字重：Black、Bold、Demi-Light。
  4. Windows：選取字體檔，按右鍵 →「為所有使用者安裝」。也可以直接複製到 C:\Windows\Fonts。
  5. Mac：連按兩下字體檔，在字體簿按「安裝字體」。
  6. 關閉再重開剪映、PPT、Word 等軟體，字體清單才會更新。
  7. 在軟體裡搜尋「獅尾」。如果清單顯示的名稱和上面不同，以清單顯示的為準。
  8. 回到本頁，上方三個字體範例變成漂亮的字形，就是安裝成功。
手機剪映怎麼辦？
  • 手機版剪映對外部字體的支援，會因版本和手機系統不同。
  • 最穩的做法：在電腦用剪映做好字卡和字幕，再匯出影片。
  • 或先在電腦做好字卡圖片，傳到手機再放進影片。

  1. 先裝字體。安裝方式在「總覽」頁最下方。裝好後重開剪映，字體清單才會出現。
  2. 貼色碼，不要用眼睛挑色。點文字顏色進色盤，找到色碼欄位，貼上複製的 HEX。描邊和背景也一樣。

04做與不做

這樣做

  • 標題 Black，副標 Bold，說明 Demi-Light
  • 每張只放一組強調色
  • 卡片底色用清新灰 #C9CACA 或溫暖灰 #E5E0DD
  • 淺底用彩色正方版 LOGO，深底用全白橫式版

不要這樣做

  • 紅色當整張背景或大色塊
  • 紅色與粉色同時出現
  • 紅字配黑外框
  • 黃色底上放白字
  • 改 LOGO 顏色、比例、加陰影
  • LOGO 寬度小於 72px（印刷小於 1.5cm）
LOGO 四周要留出 F 圖標寬度一半的空白。
